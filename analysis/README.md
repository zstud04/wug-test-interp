# Notebook analyses

This folder contains code to generate plots/analyses for embeddings training, eval, and causal interventions/

- movement.R: Visualize learning trajectories of embeddings, with CIs.

## embeddings/
- attractors_eval.ipynb: [DEPRECATED] Evaluation on old attractors stim.
- embed_param_selection.ipynb: code for visualizing systematic runs across different learning rates, as well as for visualizing CIs for 50-seed runs at certain learning rates.

## interp/
- eval_baseline.ipynb: Results on natural/wug attractor stimuli for attractors 0...3.
- full_interp.ipynb: Results for Qwen-3-VL-2/4B for all intervention methods.
